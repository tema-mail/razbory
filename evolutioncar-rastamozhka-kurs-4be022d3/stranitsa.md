# Калькуляторы растаможки РБ и РФ и откуда брать курс

**Вывод: для Беларуси надёжен только официальный калькулятор ГТК, но он считает одну пошлину. Для России лучший – calcus.ru: считает всё и встраивается на сайт. Курс брать из трёх бесплатных официальных API: НБРБ для BYN, ЦБ РФ для рублей, Народный банк Китая для пары юань–доллар. Итог для сайта: свой калькулятор под ключ на курсе НБРБ, сверенный с ГТК.**

Проверено 15.11.2026 на одной машине: Zeekr 8X Max 55, новый, в Китае 356 800 ¥ (48 389 € по курсу ЕЦБ), двигатель 1 969 см³, 898 л.с., физлицо для себя.

## 3. Курс: откуда брать

Все три бесплатные, без ключа, проверены запросом 15.11.2026:

| Пара | Источник | Адрес | Курс |
|---|---|---|---|
| BYN | Нацбанк РБ | `api.nbrb.by/exrates/rates?periodicity=0` | USD 3,0026 · EUR 3,3312 · 10 CNY 4,5143 (15.11) |
| RUB | ЦБ РФ | `cbr.ru/scripts/XML_daily.asp` (зеркало JSON: `cbr-xml-daily.ru/daily_json.js`) | USD 82,1516 · EUR 91,0322 · CNY 12,3149 (14.11) |
| USD/CNY | Народный банк Китая, центральный курс | `chinamoney.com.cn/.../ccpr.json` | 6,7152 (13.11) |

**Какой курс для чего:**
- **Таможня РБ** считает в евро по курсу НБРБ на день декларации. **Таможня РФ** – по курсу ЦБ. Значит, в калькуляторе пошлины курс только этих банков.
- **Цену из Китая в $ и BYN** для витрины считать через курс НБРБ: 1 $ = 6,65 ¥. Через ЦБ – 6,67 ¥, по Народному банку Китая – 6,72 ¥: разница около 1 %.
- **Реальная оплата в Китай** идёт через платёжного агента, и его курс обычно хуже официального на несколько процентов. Это наценка, которую знает только Evolution. Её надо заложить в цену под ключ отдельной строкой.

**Пример – Zeekr 8X Max 55, 356 800 ¥:** 161 070 BYN = 53 644 $ по НБРБ, или 4 393 956 ₽ по ЦБ.

## 4. Что делаем на сайте

1. Свой калькулятор под ключ для Беларуси: курс НБРБ подтягивается раз в день через API, единая ставка по таблице, утильсбор, сбор 120 BYN, доставка и наша работа. Каждый расчёт сверяем с ГТК.
2. На карточках моделей цена в Китае пересчитывается в $ и BYN по НБРБ с датой курса.
3. Для России, если будет нужно, встраиваем виджет calcus.ru.
