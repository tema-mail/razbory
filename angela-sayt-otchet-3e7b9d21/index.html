Ждёт от тебя

  1. Бот для заявок. Адрес website_leads_bot занят чужим ботом – выбери: website_leads2_bot или permanentbogatyryova_leads_bot. Потом токен и «Анжела нажала Запустить». Пока бота нет, заявки копятся в кабинете без уведомлений.
  2. Ссылка на MAX – пункт в окне «Связаться» стоит пустым.
  3. Search Console. У проекта Google нашего ключа выключен сервис подтверждения сайтов. Одно из двух: включить его по ссылке в твоём аккаунте Google Cloud (проект 630219646968, Site Verification API) – или добавить сайт в Search Console самому и выдать доступ teyes-seo-admin@teyes-seo-admin.iam.gserviceaccount.com.
  4. Автопубликация из редактора. Сейчас правка из редактора уходит на сайт моей ручной выкладкой. Для автоматики нужен ключ GitHub → сервер; система безопасности не дала мне его поставить сама – нужно твоё разрешение.
  5. Тексты услуг: автор макета пометил описания всех услуг, кроме губ, как черновые. Показать Анжеле – правки она может внести сама в редакторе.
  6. Дубль сайта на deford2027.github.io/permanent-makeup – выключить там Pages (у нас только чтение).
  7. Пароль reg.ru Анжелы лучше сменить – он остался в чате.
