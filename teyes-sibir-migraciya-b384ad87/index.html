Открыть сайт для поиска в день переезда

Все 3,929 страниц копии стоят с noindex, nofollow – это правильно, пока копия дублирует живой сайт. В сборке для боевого домена снять, добавить robots.txt со ссылкой на карту сайта, собрать sitemap.xml только из страниц с кодом 200 и canonical на себя, сделать страницу 404 с настоящим кодом 404. Сейчас нет ни одного из трёх файлов.

Сервер: 301, а не 308, и адреса без слэша

Canonical у страниц без слэша на конце (/multimedia_teyes/honda), а файлы лежат папками. Сервер должен отдавать страницу по адресу без слэша сразу, без перехода. Caddy по умолчанию перенаправляет кодом 308 – Яндекс такие не склеивает (проверено в октябре на 19 сайтах), поэтому в файле редиректов код 301 прописан явно.

День переезда по шагам

  1. За неделю: исправления из блока «обязательно», сборка боевой версии, проверка seo_audit.py – ноль в колонках «нет canonical», «нет description», «с битыми ссылками».
  2. Сервер (Beget или другой): Caddy, файл caddy-redirects.txt внутри блока сайта, адреса без слэша без перехода, https и одно зеркало без www – кодом 301.
  3. Проверка на сервере до DNS: 50 адресов из карты с заявками – код 200 или 301 на нужную цель (скрипт пройдёт все 5 535).
  4. Переключение DNS. Тильду не удалять 30 дней – это откат.
  5. В тот же день: Вебмастер и Search Console – отправить sitemap, переобход 50 главных адресов (агент yandex-dannye).
  6. Две недели: каждый день входы с поиска и заявки против прошлого года, ошибки 404 в Вебмастере. Проседание больше 20% на неделе – разбираем адреса.
