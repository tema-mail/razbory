# Google Карты Баланса: API одобрен, все 5 карточек теперь в твоём основном аккаунте

Заявку на API Google одобрили, поэтому вяжем через API, как ты просил. Доступ выдан и принят. Чтобы завод выкладывал сам, осталось два шага.

## API одобрен

- Квота Business Profile API в проекте teyes-seo-admin – 300 запросов в минуту. До одобрения там был 0.
- Включил Google My Business API (v4) – через него выходят публикации. До одобрения его страница не открывалась.
- Проверил живым запросом: под твоим аккаунтом список публикаций всех клубов читается без ошибок.

## Доступ выдан и принят

- Под аккаунтом Баланса твоему основному аккаунту (Artem Galimov) выдана роль «Владелец» на 5 карточек: Абрикосово, Адмирал, Империал, Balance кафе, Balance спа.
- Приглашения приняты через API. Теперь в твоём аккаунте видно 7 карточек: 5 Баланса и 2 TEYES.
- Главный владелец карточек остаётся аккаунт Баланса – у клиента ничего не отобрали.
