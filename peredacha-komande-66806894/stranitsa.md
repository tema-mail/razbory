# Передача скиллов команде – через общий GitHub

**Вывод:** записал в скилл `peredat-sotrudniku`: скиллы и агентов команде передаём через один закрытый репо на GitHub, у всех обновляется само. Пока репо нет – публичная страница с кнопкой, как у набора «Переезд».

## Что записано в скилл

- Основной путь – закрытый репо `<организация>/komanda-claude`: скиллы, агенты, хуки и установщик. Сотрудник ставит его один раз кнопкой, дальше Claude при старте подтягивает свежие версии.
- Передать скилл = положить его в этот репо. У команды он обновится при следующем запуске.
- В общий репо не идут твоя память, твой CLAUDE.md, ключи, доступы клиентов и твой голос.
- Пока репо нет – запасной путь: публичный набор на tema-mail.github.io/nabory/ и только то, что не жалко показать всем.

## Цена

- GitHub Free для организации – 0 ₽, закрытых репо и людей без ограничений. Нам этого хватит.
- GitHub Team – 4 USD на человека в месяц, только если нужны закрытые страницы или запрет прямых правок.
