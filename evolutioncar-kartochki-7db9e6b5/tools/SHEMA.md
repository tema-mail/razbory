# Данные карточки модели – схема `data/<proj>.json`

Одна модель – один файл, имя = имя проекта конфигуратора (`zeekr-7x-konfigurator.json`).
Версии и id версий – СТРОГО из `tools/konfiguratory.json` (поле `versions[].id`, `name`). Порядок версий – как там.

Язык – русский. Тире только короткое «–», длинное «—» запрещено. Никаких иероглифов. Без маркетинговой воды и метафор:
обычный понятный текст с цифрами. Ничего не выдумывать: нет проверенной цифры – `null`, на странице встанет «[уточнить]».
