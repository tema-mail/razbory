# Mobile.de: официальный API есть, но по договору; бюджетный путь – готовый сборщик

**Вывод.** У mobile.de есть официальный API для поиска и скачивания объявлений, но доступ выдаёт их поддержка под договор партнёра. Пока его нет, бюджетный путь – готовый сборщик на Apify: от 0,59 $ за 1 000 машин, без своих прокси. Свой сборщик на mobile.de не советую. Разбор от 20.11.2026.

## 1. Официальный API есть

- **Search API** – поиск по марке, модели, цене, дате изменения и скачивание объявления целиком: цена, фото, продавец, характеристики.
- **Ad-Stream** – поток событий «объявление создано или изменено». Это готовая ежедневная сверка без обхода списков.
- **Доступ – по заявке.** Нужен «API-аккаунт», его включает поддержка mobile.de. Дилерский аккаунт даёт доступ только к своим машинам. Адрес для заявки на тестовый доступ: service@team.mobile.de.
- **Ограничение:** один поиск отдаёт не больше 2 000 объявлений, большие выборки надо дробить по цене или году.
- **Цену и условия не нашёл.** Дают ли доступ компании из РБ или РФ – тоже неизвестно, надо спрашивать.

Источники: [обзор API mobile.de](https://services.mobile.de/manual/index.html), [документация Search API](https://services.mobile.de/manual/search-api.html).

## 2. Напрямую сайт закрыт

- **Прямой запрос получил отказ.** Главная и поиск ответили кодом 403 «Zugriff verweigert». Защита от роботов у mobile.de самая сильная из всех наших площадок.
- **robots.txt закрывает `/api/`.**
- **Свой сборщик здесь – самый дорогой в сопровождении.** Защита меняется часто, чинить придётся постоянно.
