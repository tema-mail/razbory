# Завод клиенту: пользоваться можно, скопировать нельзя

**Вывод.** Завод отдаём только как сервис на нашем сервере. Клиент получает кабинет, где вводит данные и донастраивает свой сайт, а код, промты станций и правила студии к нему физически не попадают. Скопировать он может только то, что видит на экране.

Разбор 16.11.2026, по коду репо zavod-ai-sfera и живому адресу zavod.сеоконтентзавод.рф.

## 1. Скопировать можно только то, что отдали

- Коробку на сервер клиента не ставим никогда. У кого root на сервере, тот читает любой код, а запутывание кода (сборка в бинарник, лицензионный ключ) только оттягивает копию на дни.
- Промты всё равно уходят в нейросеть открытым текстом: на своём сервере клиент увидит их в трафике.
- Значит, защита – не «спрятать код», а «не отдавать код»: завод живёт у нас, клиент ходит в окно по логину. Так устроены все сервисы по подписке.
- Сейчас уже так и есть: кабинет клиента – адрес /<клиент>, свой логин, только свой сайт; пульт и API владельца без входа отвечают 401 (проверено снаружи 16.11).

## 2. «Донастраивать» – это настройки в окне, а не доступ к системе

Делим завод на два слоя.

| Слой клиента – видит и меняет | Слой студии – только на сервере |
|---|---|
| Факты о компании: цены, сроки, гарантии | Промты всех 13 станций |
| Красный список своего сайта | Красный список студии и гейты проверки |
| Каналы, расписание, «без одобрения не выкладывать» | Логика спроса, кластеров и карты страниц |
| Темы, тон, филиалы | Правила площадок и модерации |
| Согласование и перенос публикаций | Ключи Яндекса, XMLRiver, Claude |
| Отчёт недели, выгрузка своих статей | Код, база других клиентов |

- Сейчас у клиента только календарь, согласование, перенос и отчёт. Чтобы он сам донастраивал, нужен экран «Настройки» с полями слоя клиента.
- Ни одна ручка клиента не должна отдавать слой студии: ни текст промта, ни «почему советник так решил» в сыром виде. Отчёт клиенту уже без записки советника и технических причин – так держать.

## 3. Что закрыть сейчас

- **Оболочка пульта открыта без входа.** Снаружи без логина отдаются index.html (63 КБ) и скрипты экранов (ekrany.js, klienty.js, resheniya.js). Данных там нет, но видно устройство всех экранов и названия станций. Закрыть: без входа отдавать только окно логина.
- **Массовое скачивание.** Лимит запросов на кабинет и журнал действий клиента – видно, если кто-то выкачивает всё подряд.
- **Ключ нейросети.** На продаже Claude у клиента – отдельный ключ API на каждого клиента, не наша подписка: условия Anthropic запрещают раздавать вход по подписке в чужом продукте без их одобрения. Плюс расход виден по каждому клиенту.
- **Техдолг:** fastapi/starlette устарели, дыра Range пока закрыта на Caddy.

## 4. Договор закрывает то, что не закрыть кодом

- Договор – лицензия на доступ к сервису, а не продажа программы. Запрет копировать, разбирать и повторять систему, штраф за нарушение.
- Тексты, статьи и данные – клиента; система, промты и методика – наши. При уходе клиент получает выгрузку своих статей и фактов, но не настройки студии.
- Доступ гаснет при неоплате одной кнопкой – это и есть «лицензия».
- Название «Завод AI сфера» – товарный знак, когда дойдём до продажи.

Чего не защитит ничего: человек смотрит на экран и повторяет идею. Защищает то, что повторить долго: 13 станций, правила и данные, которые копятся каждый день.

## Если клиент просит «поставьте нам на наш сервер»

Не рекомендую. Компромисс: сервер оформлен на клиента, но root и обновления только у нас, это прописано в договоре. Копию это не исключает, но делает её нарушением договора.

## План с ценой (прогноз)

| Шаг | Что | Часы |
|---|---|---|
| 1 | Оболочку пульта – за вход; проверка снаружи; ревизия ручек клиента «слой студии не отдаётся» | 2–3 |
| 2 | Экран «Настройки» у клиента (факты, красный список сайта, каналы, расписание, тон, темы) + журнал действий + лимит выгрузок | 10–15 |
| 3 | На продажу: ключ Claude API на клиента, расход по клиенту, выключатель доступа по оплате | 15–25 |
| – | Договор-лицензия – шаблон у юриста | не наши часы |

## Нужно от тебя

1. «Да» на шаг 1 – закрыть оболочку пульта за вход.
2. Какие настройки отдать клиенту в шаге 2: весь список из таблицы или меньше.
3. Код завода сегодня правили сразу несколько чатов (проверка kto-v-proekte, 16.11). Выбрать один главный чат завода, иначе правки будут наезжать друг на друга.
