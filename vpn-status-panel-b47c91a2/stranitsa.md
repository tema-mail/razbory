# Панель показывает INCY, внешний IP и доступность Claude каждые 30 секунд

**Вывод:** на Mac запущена локальная панель VPN. Она показывает только реальные измерения и не выдаёт зелёный статус, пока внешний IP не совпадает с VPS.

**Открыть на Mac:** http://127.0.0.1:8765/

## Что видно на экране

- **Соединение INCY** – подключён ли системный VPN-профиль.
- **Внешний IP и страна** – основная проверка идёт по точному совпадению IP с сервером, а не только по коду страны.
- **Claude API** – HTTP-код и задержка `api.anthropic.com`. Ответ `401` ожидается без API-ключа и означает техническую доступность API.
- **Net.Coffee** – отдельная кнопка для Trust Score и репутации IP.
- Время последнего обновления и кнопка ручного обновления.

Зелёный общий статус появляется только при трёх условиях: INCY подключён, IP равен адресу VPS, Claude ответил `200` или `401`. При сбое старые успешные показания сбрасываются, а не остаются на экране.

| Проверка | Результат |
|---|---|

| API `/health` | HTTP 200 |
| Чужой `Host` | HTTP 403 |
| Чужой `Origin` | HTTP 403 |
| Текущий INCY | Подключён |
| Текущий IP | Не совпадает с VPS, поэтому общий статус оранжевый |
| Claude API | HTTP 401, доступен |
| Независимое ревью | PASS после исправления состояний ошибок, кэша и проверок доступа |

Разные базы могут называть разные страны для одного IP. Поэтому панель не считает надпись `NL` достаточным доказательством: сравнивается сам адрес сервера.

```bash

```

Затем снова открой http://127.0.0.1:8765/. Сервер слушает только этот Mac и не опубликован в интернете.

## Что важно знать

- Панель не меняет VPN и не подтверждает аккаунт Claude. Она показывает сетевую доступность сервиса.
- Для репутации IP и дополнительных утечек используй кнопку Net.Coffee.
- Старые неудачные варианты нативного окна удалены. Остались три файла: `checks.py`, `server.py` и `index.html` в `vpn-status/`.
