2. Что мешает (техника раньше контента)

  1. Google держит http-версию главной. http://mds.by/ в Google собрал 5 773 показа и 90 кликов за месяц – больше показов, чем https-главная (4 767). Сейчас 301 на https стоит, нужно проверить склейку в Search Console и не потерять это при переносе.
  2. Search Console по API. Данные Google сняты через кабинет Артёма, по API доступа нет: Артём в ресурсе mds.by не владелец. Владелец ресурса должен добавить teyes-seo-admin@teyes-seo-admin.iam.gserviceaccount.com, тогда отчёт будет собираться сам.
  3. В Google проиндексирован шаблонный пост блога «the-third-title-for-the-post» – мусор с Тильды, убрать при переносе.
  4. Яндекс Вебмастер молчит с 08.10 – авария Яндекса. Позиции Яндекса за последний месяц сейчас не измерить, только через съём выдачи (XMLRiver).

4. Формула прогноза

Спрос (Я+G) = горячий спрос Яндекса × 2,497
Визиты/мес = Спрос (Я+G) × выход
  цель: выход 2 % (страница в топ-10, на 7–10 месте)
  максимум: выход 4,5 % (как у оклейки MDS сейчас: позиция 7,4, клики/показы 4,5 %)
Для страниц, которые уже есть: max(сейчас, прогноз)
Обращения = визиты × 5 %
Фраз в топ-10 = фразы страницы со спросом от 10 в мес × 40 % (цель) / 70 % (максимум)
  • ×2,497 – Вордстат видит только Яндекс. Доля поисковиков в Беларуси по StatCounter за октябрь 2026: Google 58,16 %, Яндекс 38,85 %; 1 + 58,16 / 38,85 = 2,497. Это осторожно: у MDS органика из Google в 1,8 раза больше, чем из Яндекса.
  • Выход 2 % – вдвое ниже того, что MDS уже получает на оклейке (4,5 %). Сюда же заложено, что страница соберёт не все хвосты своего спроса.
  • Конверсия 5 % – ниже замера: сейчас 8,5–12,8 % визитов из органики заканчиваются формой, кликом по телефону или мессенджером.
  • Срок – индексация 1–3 недели, выход в топ-10 по Минску – 2–4 месяца, ровная цифра через 4–6 месяцев после выкладки. Гарантии нет; в Яндексе ещё и последствия аварии.
  • Главный риск – концентрация: антикор (317), оклейка (183) и тонировка (98) – 42 % минимального прогноза. По антикору сейчас 12-я позиция, там сильнее всего конкуренция.

5. Что решить

  1. Попросить владельца ресурса mds.by в Search Console добавить наш сервисный ключ (почта выше) – тогда Google по API, без ручного входа.
  2. Утвердить план по спросу вместо релизов: страницы услуг поделены на три месяца от крупных к мелким, блог – 30 статей в первый месяц и по 150 во второй и третий.
  3. Добавить в Search Console mds.by наш сервисный ключ (Артём теперь владелец ресурса) – тогда Google будет сниматься по API.
  4. Темы без прямого спроса («Защита нового авто», «После зимы», «Авто из США», марки) собраны облаком формулировок; где облако набирает от 20 в мес – страница + статья, иначе раздел.
